# Schema — inline for review

Two objects. Measure fields have identical API names on both, `Amount_` prefixed so a describe scan finds them without a hardcoded list. All amounts signed: removals negative, always.

---

## Object 1 — `Quote_Document_Table__c`

**Label:** Quote Document Table
**Plural:** Quote Document Tables
**Record Name:** Table Name — Text(80)
**Sharing:** Controlled by Parent (Master-Detail)
**Allow Reports:** Yes · **Allow Activities:** No · **Track Field History:** No

Description: *One generated table for a Quote, intended for a downstream document. Each record represents a complete table with its own rows and totals. Generated content only — Quote Lines remain the source of truth.*

### Relationship

| Field | API Name | Type | Req | Default | Help Text |
|---|---|---|---|---|---|
| Quote | `Quote__c` | Master-Detail → `SBQQ__Quote__c` | Yes | — | The Quote this table was generated from. Tables are deleted when the Quote is deleted. |

Child Relationship Name: `DocumentTables` · Reparenting: not allowed · Sharing: read-only

### Identity

| Field | API Name | Type | Req | Default | Help Text |
|---|---|---|---|---|---|
| Table Name | `Name` | Text(80) | Yes | — | Business name of the table, such as Product Family Summary. Set during generation. Do not use this value in integrations; use Table Code. |
| Table Code | `Table_Code__c` | Text(60) | Yes | — | Stable identifier for the type of table, such as PRODUCT_FAMILY_SUMMARY. Integrations and document templates must reference this value rather than the table name. |
| Table Key | `Table_Key__c` | Text(120), External ID, Unique | Yes | — | Unique key in the form QuoteId:TableCode. Used to regenerate a table without creating duplicates. |
| Display Order | `Display_Order__c` | Number(3,0) | No | `10` | Order of this table within the document. Use increments of ten so tables can be inserted later without renumbering. |

### Meaning

| Field | API Name | Type | Req | Default | Help Text |
|---|---|---|---|---|---|
| Amount Basis | `Amount_Basis__c` | Picklist | Yes | `Net Change` | The financial basis of all amounts in this table. Two tables with the same structure can carry different meanings, so this value must accompany the generated data. |
| Group Dimensions | `Group_Dimensions__c` | Text(255) | No | — | The grouping applied when this table was generated, outermost first, such as Industry > Product Family. Recorded for traceability. |

`Amount_Basis__c` values: Net Change · Final Value · TCV · ACV · First-Year Value · Remaining-Term Value · Recurring Value · One-Time Value

### Lifecycle

| Field | API Name | Type | Req | Default | Help Text |
|---|---|---|---|---|---|
| Status | `Status__c` | Picklist | Yes | `Generating` | Generation state. Only tables marked Complete may be consumed by a document. |
| Generated On | `Generated_On__c` | Date/Time | No | — | When this table was generated. Compare against the Quote's last modified date to identify a table that no longer reflects the Quote. |
| Generation Version | `Generation_Version__c` | Number(4,0) | No | — | Version of the generation logic that produced this table. Required to explain why an older document shows different values from current logic. |
| Row Count | `Row_Count__c` | Number(5,0) | No | — | Number of rows written during generation. A consuming system can compare this against the rows it retrieved to detect an incomplete pull. |
| Error Message | `Error_Message__c` | Long Text Area(4000) | No | — | Details of a generation failure. Internal use only; never displayed in a document. |

`Status__c` values: Generating (default) · Complete · Failed

### Measures

All Currency(16,2). Not required. No default.

| Field | API Name | Help Text |
|---|---|---|
| Net New Amount | `Amount_Net_New__c` | Total value classified as new business or expansion. Positive. |
| Cancellation Amount | `Amount_Cancellation__c` | Total value removed through cancellation. Stored as a negative number. |
| Replacement Removed Amount | `Amount_Replacement_Removed__c` | Total value of products removed as part of a replacement. Stored as a negative number. Not counted as cancellation. |
| Replacement Added Amount | `Amount_Replacement_Added__c` | Total value of products added as part of a replacement. Positive. |
| Termination Amount | `Amount_Termination__c` | Total value removed through termination of an active contract. Stored as a negative number. |
| Net Change Amount | `Amount_Net_Change__c` | Signed commercial effect of all changes in this table. Equals the sum of the measures above. |
| Final Amount | `Amount_Final__c` | Final value represented by this table, interpreted according to Amount Basis. |

Computed in Apex during generation, from rows where `Include_In_Grand_Total__c = true`. Not roll-up summaries — rows include subtotal and grand-total records, so a roll-up would double-count.

### Standard

`CurrencyIsoCode` if multi-currency is enabled. Must match the Quote's currency.

## Object 2 — `Quote_Document_Row__c`

**Label:** Quote Document Row
**Plural:** Quote Document Rows
**Record Name:** Row Number — Auto Number `QDR-{0000000000}`
**Sharing:** Controlled by Parent
**Allow Reports:** Yes · **Allow Activities:** No

Description: *One row within a generated table. Covers group headers, detail rows, subtotals, section totals and grand totals. Grouping labels and product names are stored as snapshots so a generated document remains reproducible.*

### Relationships

| Field | API Name | Type | Req | Help Text |
|---|---|---|---|---|
| Quote Document Table | `Quote_Document_Table__c` | Master-Detail | Yes | The table this row belongs to. |
| Source Quote Line | `Quote_Line__c` | Lookup → `SBQQ__QuoteLine__c` | No | The Quote Line this row was generated from. Populated on detail rows only; blank on headers and totals. |
| Product | `Product__c` | Lookup → `Product2` | No | Current Product record for reporting. Displayed values come from the snapshot fields, not from this lookup. |
| Parent Row | `Parent_Row__c` | Lookup → self | No | The group row containing this row. Used for nested groupings. |

Relationship names: `Rows` (table), `DocumentRows` (quote line, product), `ChildRows` (self). Reparenting on the Master-Detail: not allowed. All lookups: Don't allow deletion of the lookup record that's part of a lookup relationship → set to **Clear the value** for Quote Line and Product; **Don't allow** would block quote line deletion.

### Structure

| Field | API Name | Type | Req | Default | Help Text |
|---|---|---|---|---|---|
| Row Type | `Row_Type__c` | Picklist | Yes | — | What this row represents. Determines how a document renders it and whether it contributes to totals. |
| Display Order | `Display_Order__c` | Number(5,0) | Yes | — | Position of this row within the table. Rows must be consumed in this order. Never rely on record creation order or record ID. |
| Row Key | `Row_Key__c` | Text(255), External ID | Yes | — | Stable identifier for this row within its table, such as SUBTOTAL:INDUSTRY:LIFE_SCIENCES. Supports regeneration without duplicates. |
| Group Level | `Group_Level__c` | Number(2,0) | Yes | — | Nesting depth. Zero is the table-level total; one is the outermost grouping. Used for indentation. |
| Source Grain | `Source_Grain__c` | Picklist | Yes | — | What the row was built from. Distinguishes a single Quote Line from an aggregated or calculated row. |

`Row_Type__c` values: Group Header · Detail · Subtotal · Section Total · Grand Total · Informational

- **Subtotal** — total for a grouping node
- **Section Total** — total for a logical portion of the table, such as Recurring Total or Tax
- **Grand Total** — final total for the entire table

`Source_Grain__c` values: Quote Line · Product · Bundle · Subscription · Segment · Group · Calculated

### Grouping

| Field | API Name | Type | Req | Help Text |
|---|---|---|---|---|
| Group Dimension | `Group_Dimension__c` | Text(80) | No | The classification this row is grouped by, such as Industry or Product Family. A label alone does not identify what kind of grouping it represents. |
| Group Value | `Group_Value__c` | Text(255) | No | Normalized grouping value, independent of how it is displayed. |
| Group Key | `Group_Key__c` | Text(255) | No | Full grouping path, such as INDUSTRY:LIFE_SCIENCES\|FAMILY:ANALYTICS. Distinguishes the same value appearing under different parents. |
| Display Label | `Display_Label__c` | Text(255) | Yes | The exact text shown in the document. Stored rather than derived so wording and translation remain fixed after generation. |

`Group_Dimension__c` is Text, not Picklist — new dimensions should not require a deployment.

### Inclusion

| Field | API Name | Type | Req | Default | Help Text |
|---|---|---|---|---|---|
| Is Displayed | `Is_Displayed__c` | Checkbox | — | `true` | Whether the document renders this row. A row may be hidden and still contribute to totals, for example a bundle child whose value is included but not shown. |
| Include In Subtotal | `Include_In_Subtotal__c` | Checkbox | — | `true` | Whether this row's amounts are included in its group subtotal. Clear for rows that are displayed but not counted, such as optional or no-charge products. |
| Include In Grand Total | `Include_In_Grand_Total__c` | Checkbox | — | `true` | Whether this row's amounts are included in the table grand total. |

Reference behaviour:

| Scenario | Displayed | Subtotal | Grand Total |
|---|---|---|---|
| Normal priced line | Yes | Yes | Yes |
| Informational line | Yes | No | No |
| Bundle child, parent carries price | Yes | No | No |
| Bundle child, hidden but counted | No | Yes | Yes |
| Optional product shown separately | Yes | No | No |
| Zero-priced included product | Yes | No | No |

Aggregate rows — Group Header, Subtotal, Section Total, Grand Total — carry `Include_In_Subtotal__c = false` and `Include_In_Grand_Total__c = false`. They are outputs of aggregation, never inputs.

### Snapshots

| Field | API Name | Type | Req | Help Text |
|---|---|---|---|---|
| Product Name | `Product_Name__c` | Text(255) | No | Product name as it appeared when generated. Preserved so a document remains reproducible if the Product is later renamed. |
| Product Code | `Product_Code__c` | Text(80) | No | Product code as it appeared when generated. |
| Product Family | `Product_Family__c` | Text(80) | No | Product family as it appeared when generated. |
| Transaction Type | `Transaction_Type__c` | Picklist | No | Why this row contributes to a measure. Blank on rows that combine multiple transaction types. |

`Transaction_Type__c` values: Net New · Cancellation · Replacement Removed · Replacement Added · Termination

### Measures

Identical seven fields, identical API names, identical help text as the table object. Currency(16,2), not required, no default. Populated on detail, subtotal, section total and grand total rows alike — the schema is the same at every level.

## Generation rules

1. Set `Status__c = 'Generating'` before writing rows. Only `Complete` is consumable.
2. Regenerate by deleting existing rows for the `Table_Key__c` and re-inserting. Do not attempt row-level diffing.
3. Assign `Display_Order__c` in increments of ten in final render order.
4. Subtotal = sum of descendant rows where `Include_In_Subtotal__c = true`, per measure.
5. Grand Total row = sum of detail rows where `Include_In_Grand_Total__c = true`, per measure.
6. Table measure fields = the Grand Total row's values, written last.
7. Write `Row_Count__c`, `Generated_On__c`, `Generation_Version__c`, then set `Status__c = 'Complete'`.
8. Any assertion failure sets `Status__c = 'Failed'`, populates `Error_Message__c`, and leaves rows in place for diagnosis.
9. Run asynchronously (Queueable). Row volume on a large quote with multiple tables is real DML.

## Validation rules

Declarative — enforceable on the record:

| Rule | Condition that must hold |
|---|---|
| `Hidden_Row_Must_Count` | If `Is_Displayed__c = false`, then `Include_In_Subtotal__c` or `Include_In_Grand_Total__c` is true. A row that is neither shown nor counted should never have been generated. |
| `Detail_Requires_Quote_Line` | If `Row_Type__c = 'Detail'` and `Source_Grain__c = 'Quote Line'`, `Quote_Line__c` is populated. |
| `Aggregate_Has_No_Quote_Line` | If `Row_Type__c` is Group Header, Subtotal, Section Total or Grand Total, `Quote_Line__c` is blank. |
| `Grand_Total_Level_Zero` | If `Row_Type__c = 'Grand Total'`, `Group_Level__c = 0`. |
| `Aggregate_Excluded_From_Totals` | If `Row_Type__c` is an aggregate type, both inclusion flags are false. |
| `Removal_Signs_Negative` | `Amount_Cancellation__c`, `Amount_Replacement_Removed__c` and `Amount_Termination__c` are ≤ 0. |
| `Display_Label_Required` | `Display_Label__c` is populated. Enforced by requiredness; a validation rule adds nothing. |

Apex-only — no validation rule can see sibling records:

- Subtotal reconciles to its children, per measure
- Grand Total reconciles two ways: sum of level-1 subtotals, and sum of included detail rows
- Table measures equal the Grand Total row
- Table total reconciles to the CPQ Quote total
- Every eligible Quote Line appears exactly once
- `Display_Order__c` and `Row_Key__c` unique within table
- `Parent_Row__c` in the same table, no cycles
- `Group_Level__c` agrees with parent-chain depth
- All rows share the table's currency

The first four are the ones that prevent a signed document carrying wrong numbers. Assert them at generation time; the rest belong in tests.

## Deferred

Not built now, listed so nobody re-derives them: `Source_Line_Count__c` (until aggregated detail rows exist), `Industry__c`, `Product_Group__c`, `Business_Unit__c`, `Existing_Amount__c`, `Amount_One_Time__c`, `Amount_Recurring__c`, quantity fields, date fields, MDQ segment fields, replacement pair lookups, `Is_Current__c`, `Table_Type__c`, `Document_Context__c`, `Quote_Document_Column__c`.

Known boundaries: only additive measures roll up and reconcile — non-additive values may be stored at any level but must be computed independently at each. Dynamic period columns are out of scope; MDQ periods render as rows via `Group_Dimension__c = 'Contract Period'`.
