Honest answer: partially, and the gaps matter.

**What debug logging will and won't show you.** CPQ's trigger code is in a managed package. Unless you have debug access to the package, its internals emit no detail lines — you'll see the DML statement and then a gap. So you cannot attribute CPU *inside* SBQQ code. What you can do is measure `Limits.getCpuTime()` deltas around the DML, which tells you the cost without the breakdown. That's the measurement that's actually available.

**The log level distorts the thing you're measuring.** Running at FINEST adds real overhead and inflates CPU. Set Apex Code to ERROR or INFO for measurement runs. That's why every statement below uses `LoggingLevel.ERROR` — they survive a low log level, so you get a small log and a clean number.

**Logs truncate.** 200 lines through CPQ triggers can blow past the 20MB cap, and you lose content. Small log level protects you here too.

**Don't measure in a test class.** CPQ needs product, pricebook, and option data that unit tests either can't see or must fabricate, and CPU in test context isn't representative. Run this as anonymous Apex in a sandbox with real data. A proper `@isTest` class is a separate exercise and a genuinely annoying one.

```apex
public with sharing class QuickQuoteHarness {

    private static Integer lastCpu = 0;
    private static Long lastMs = 0;

    public static void reset() {
        lastCpu = Limits.getCpuTime();
        lastMs = System.currentTimeMillis();
    }

    public static void mark(String label) {
        Integer cpu = Limits.getCpuTime();
        Long ms = System.currentTimeMillis();
        System.debug(LoggingLevel.ERROR, '### ' + label
            + ' | CPU ' + cpu + 'ms (+' + (cpu - lastCpu) + ')'
            + ' | wall +' + (lastMs == 0 ? 0 : ms - lastMs) + 'ms'
            + ' | SOQL ' + Limits.getQueries() + '/' + Limits.getLimitQueries()
            + ' | DML ' + Limits.getDmlStatements() + '/' + Limits.getLimitDmlStatements()
            + ' | Rows ' + Limits.getDmlRows() + '/' + Limits.getLimitDmlRows()
            + ' | Heap ' + Limits.getHeapSize() + '/' + Limits.getLimitHeapSize());
        lastCpu = cpu;
        lastMs = ms;
    }

    // ---------- discovery: find what's actually testable in your org ----------

    public static void showBundleCandidates() {
        System.debug(LoggingLevel.ERROR, '### Products configured as bundles:');
        for (AggregateResult ar : [
            SELECT SBQQ__ConfiguredSKU__r.ProductCode code, COUNT(Id) cnt
            FROM SBQQ__ProductOption__c
            WHERE SBQQ__ConfiguredSKU__r.ProductCode != null
            GROUP BY SBQQ__ConfiguredSKU__r.ProductCode
            ORDER BY COUNT(Id) DESC
            LIMIT 10
        ]) {
            System.debug(LoggingLevel.ERROR, '  ' + ar.get('code') + ' -> ' + ar.get('cnt') + ' options');
        }
    }

    public static void showOptions(String bundleCode) {
        System.debug(LoggingLevel.ERROR, '### Options for ' + bundleCode + ':');
        for (SBQQ__ProductOption__c po : [
            SELECT SBQQ__OptionalSKU__r.ProductCode, SBQQ__OptionalSKU__r.Name, SBQQ__Required__c
            FROM SBQQ__ProductOption__c
            WHERE SBQQ__ConfiguredSKU__r.ProductCode = :bundleCode
            ORDER BY SBQQ__Number__c
        ]) {
            System.debug(LoggingLevel.ERROR, '  ' + po.SBQQ__OptionalSKU__r.ProductCode
                + ' | ' + po.SBQQ__OptionalSKU__r.Name
                + ' | required=' + po.SBQQ__Required__c);
        }
    }

    public static void showOpportunity(Id oppId) {
        Opportunity o = [SELECT Id, Name, AccountId, Pricebook2Id FROM Opportunity WHERE Id = :oppId];
        System.debug(LoggingLevel.ERROR, '### Opp ' + o.Name
            + ' | Account=' + o.AccountId + ' | Pricebook=' + o.Pricebook2Id);
        if (o.Pricebook2Id == null) {
            System.debug(LoggingLevel.ERROR, '### WARNING: no pricebook. Lines will have null PricebookEntry.');
        }
    }

    // ---------- scenarios ----------

    public static Id runFlat(Id oppId, List<String> productCodes) {
        List<Object> lines = new List<Object>();
        for (String c : productCodes) lines.add(mkLine(c, 1, null));
        return run('FLAT(' + productCodes.size() + ')', oppId, lines);
    }

    public static Id runBundle(Id oppId, String bundleCode, List<String> optionCodes) {
        return run('BUNDLE', oppId, new List<Object>{ mkBundle(bundleCode, optionCodes) });
    }

    public static Id runMixed(Id oppId, String bundleCode, List<String> optionCodes, List<String> flatCodes) {
        List<Object> lines = new List<Object>{ mkBundle(bundleCode, optionCodes) };
        for (String c : flatCodes) lines.add(mkLine(c, 1, null));
        return run('MIXED', oppId, lines);
    }

    public static Id runCustomFields(Id oppId, String productCode, Map<String, Object> fields) {
        return run('FIELDS', oppId, new List<Object>{ mkLine(productCode, 1, fields) });
    }

    public static Id runScale(Id oppId, String productCode, Integer lineCount) {
        List<Object> lines = new List<Object>();
        for (Integer i = 0; i < lineCount; i++) lines.add(mkLine(productCode, 1, null));
        return run('SCALE(' + lineCount + ')', oppId, lines);
    }

    // ---------- plumbing ----------

    private static Map<String, Object> mkLine(String code, Decimal qty, Map<String, Object> fields) {
        return new Map<String, Object>{
            'productCode' => code, 'quantity' => qty, 'fields' => fields
        };
    }

    private static Map<String, Object> mkBundle(String bundleCode, List<String> optionCodes) {
        List<Object> opts = new List<Object>();
        for (String c : optionCodes) opts.add(mkLine(c, 1, null));
        Map<String, Object> parent = mkLine(bundleCode, 1, null);
        parent.put('options', opts);
        return parent;
    }

    private static Id run(String label, Id oppId, List<Object> lines) {
        String payload = JSON.serialize(new Map<String, Object>{
            'quoteFields' => new Map<String, Object>(),
            'lines' => lines
        });

        reset();
        mark(label + ' :: start');

        Id quoteId;
        try {
            quoteId = QuickQuoteBuilder.build(oppId, payload);
            mark(label + ' :: build complete');
        } catch (Exception e) {
            mark(label + ' :: FAILED');
            System.debug(LoggingLevel.ERROR, '### ' + e.getTypeName() + ': ' + e.getMessage());
            System.debug(LoggingLevel.ERROR, e.getStackTraceString());
            return null;
        }

        verify(quoteId);
        mark(label + ' :: done');
        return quoteId;
    }

    // ---------- verification ----------

    public static void verify(Id quoteId) {
        SBQQ__Quote__c q = [
            SELECT Id, Name, SBQQ__Primary__c, SBQQ__NetAmount__c
            FROM SBQQ__Quote__c WHERE Id = :quoteId
        ];
        System.debug(LoggingLevel.ERROR, '### Quote ' + q.Name
            + ' | primary=' + q.SBQQ__Primary__c
            + ' | netAmount=' + q.SBQQ__NetAmount__c);

        List<SBQQ__QuoteLine__c> lines = [
            SELECT Id, SBQQ__Product__r.ProductCode, SBQQ__Quantity__c,
                   SBQQ__RequiredBy__c, SBQQ__ProductOption__c, SBQQ__Bundle__c,
                   SBQQ__PricebookEntryId__c, SBQQ__ListPrice__c, SBQQ__NetTotal__c
            FROM SBQQ__QuoteLine__c
            WHERE SBQQ__Quote__c = :quoteId
            ORDER BY SBQQ__RequiredBy__c NULLS FIRST
        ];

        Integer unpriced = 0, noPbe = 0, orphaned = 0;
        for (SBQQ__QuoteLine__c l : lines) {
            Boolean isChild = l.SBQQ__RequiredBy__c != null;
            System.debug(LoggingLevel.ERROR, (isChild ? '    +-- ' : '  ')
                + l.SBQQ__Product__r.ProductCode
                + ' qty=' + l.SBQQ__Quantity__c
                + ' bundle=' + l.SBQQ__Bundle__c
                + ' hasOption=' + (l.SBQQ__ProductOption__c != null)
                + ' pbe=' + (l.SBQQ__PricebookEntryId__c != null)
                + ' list=' + l.SBQQ__ListPrice__c
                + ' net=' + l.SBQQ__NetTotal__c);

            if (l.SBQQ__NetTotal__c == null) unpriced++;
            if (l.SBQQ__PricebookEntryId__c == null) noPbe++;
            if (isChild && l.SBQQ__ProductOption__c == null) orphaned++;
        }

        System.debug(LoggingLevel.ERROR, '### ' + lines.size() + ' lines'
            + ' | unpriced=' + unpriced
            + ' | missingPricebookEntry=' + noPbe
            + ' | childrenWithoutProductOption=' + orphaned);
    }

    public static void cleanup(Id oppId) {
        List<SBQQ__Quote__c> qs = [SELECT Id FROM SBQQ__Quote__c WHERE SBQQ__Opportunity2__c = :oppId];
        delete qs;
        System.debug(LoggingLevel.ERROR, '### deleted ' + qs.size() + ' quotes');
    }
}
```

Run it in this order, in anonymous Apex:

```apex
Id oppId = '006XXXXXXXXXXXXXXX';

QuickQuoteHarness.showOpportunity(oppId);
QuickQuoteHarness.showBundleCandidates();
QuickQuoteHarness.showOptions('YOUR-BUNDLE-CODE');
```

Then, separately:

```apex
Id oppId = '006XXXXXXXXXXXXXXX';

QuickQuoteHarness.runFlat(oppId, new List<String>{ 'CODE-A', 'CODE-B' });
QuickQuoteHarness.runBundle(oppId, 'BUNDLE-CODE', new List<String>{ 'OPT-1', 'OPT-2' });
QuickQuoteHarness.runMixed(oppId, 'BUNDLE-CODE', new List<String>{ 'OPT-1' }, new List<String>{ 'CODE-A' });
QuickQuoteHarness.runCustomFields(oppId, 'CODE-A', new Map<String, Object>{ 'Site_Count__c' => 12 });
```

Scale test last, one run per execution so the numbers aren't contaminated:

```apex
QuickQuoteHarness.runScale('006XXXXXXXXXXXXXXX', 'CODE-A', 200);
```

The three counters at the end of `verify` are the ones that tell you whether the build is actually correct rather than merely not throwing. `childrenWithoutProductOption` above zero means the option resolution failed and you've got flat lines pretending to be a bundle — which inserts cleanly and breaks later. `missingPricebookEntry` above zero means the pricebook lookup missed and calculation will not price those lines.

`unpriced` will be nonzero on every run, because nothing here calls the Calculate API. That's expected, not a bug.

Two caveats on the harness itself: the `ORDER BY SBQQ__RequiredBy__c NULLS FIRST` groups parents ahead of children but doesn't truly nest the output, so with several bundles the indentation is indicative rather than structural. And `cleanup` deletes every quote on the Opportunity, so don't point it at anything real.
