Before the code — the review is mostly sound, but three points are wrong or misapplied, and it misses the one that actually matters now.

**Where it's wrong.** The savepoint suggestion for the harness is backwards: rolling back destroys the records you're trying to inspect in the UI afterward. A diagnostic that deletes its own evidence is worse than one that leaves debris. Savepoints belong in the service, per quote, not wrapped around the measurement. Point 8 (relationship dereferences) is technically true only when the lookup is null, and in `verify()` every line was just created with `SBQQ__Product__c` populated, so it can't be. Point 9 restates the FLS caveat I'd already flagged as a blocker.

Point 7 is a fair hit — "unpriced will be nonzero on every run" was too absolute. A Quote Calculator Plugin or custom automation on insert can populate prices.

Points 5 and 6 are the good ones, and they're the real gap: verifying that a child's `SBQQ__ProductOption__c` is non-null proves nothing about whether it's the *right* option, and nothing compares what was created against what was requested.

**What nobody flagged.** Making this invocable reintroduces the problem we spent the whole design conversation solving. A Flow-invoked method runs synchronously at 10,000ms CPU, not the 60,000ms you'd get in a Queueable. Worse, invocables are bulkified — a record-triggered Flow on 5 Opportunities delivers 5 requests in *one* transaction. Five requests × 200 lines is 1,000 quote lines through CPQ's managed triggers in a synchronous context. That will not complete.

So the invocable below has a hard line-count ceiling that fails loudly rather than dying on a CPU timeout you can't catch. Treat that number as a placeholder until you measure.

```apex
public with sharing class CpqQuoteCreationService {

    public class QuoteCreationException extends Exception {}

    // Placeholder. Lower it once you have real CPU numbers from your org.
    private static final Integer MAX_LINES_PER_INVOCATION = 150;

    // Fields this service owns. A payload must never set them.
    private static final Set<String> BLOCKED_FIELDS = new Set<String>{
        'sbqq__quote__c', 'sbqq__product__c', 'sbqq__requiredby__c',
        'sbqq__productoption__c', 'sbqq__bundle__c', 'sbqq__pricebookentryid__c',
        'sbqq__opportunity2__c', 'sbqq__account__c', 'sbqq__primary__c',
        'sbqq__listprice__c', 'sbqq__netprice__c', 'sbqq__customerprice__c',
        'sbqq__regularprice__c', 'sbqq__specialprice__c', 'sbqq__nettotal__c'
    };

    private static Map<String, Map<String, Schema.SObjectField>> describeCache =
        new Map<String, Map<String, Schema.SObjectField>>();

    // ---------- payload ----------

    public class QuoteInput {
        public Map<String, Object> quoteFields;
        public List<LineInput> lines;
    }

    public class LineInput {
        public String productCode;
        public Decimal quantity;
        public Map<String, Object> fields;
        public List<LineInput> options;
    }

    // ---------- invocable ----------

    public class Request {
        @InvocableVariable(label='Opportunity Id' required=true)
        public String opportunityId;

        @InvocableVariable(label='Quote Payload JSON' required=true)
        public String payloadJson;
    }

    public class Result {
        @InvocableVariable(label='Success')
        public Boolean success;

        @InvocableVariable(label='Quote Id')
        public String quoteId;

        @InvocableVariable(label='Lines Created')
        public Integer lineCount;

        @InvocableVariable(label='Error Message')
        public String errorMessage;
    }

    @InvocableMethod(
        label='Create CPQ Quote'
        description='Creates a CPQ quote and quote lines on an Opportunity from a JSON payload.'
        category='CPQ')
    public static List<Result> createQuotes(List<Request> requests) {
        List<Result> results = new List<Result>();
        Integer linesSoFar = 0;

        for (Request req : requests) {
            Result res = new Result();
            res.success = false;
            res.lineCount = 0;

            Savepoint sp = Database.setSavepoint();
            try {
                if (String.isBlank(req.opportunityId)) {
                    throw new QuoteCreationException('Opportunity Id is required.');
                }
                if (String.isBlank(req.payloadJson)) {
                    throw new QuoteCreationException('Payload JSON is required.');
                }

                QuoteInput input = parse(req.payloadJson);
                Integer lineCount = countLines(input);

                if (linesSoFar + lineCount > MAX_LINES_PER_INVOCATION) {
                    throw new QuoteCreationException(
                        'Aborted before insert: this request adds ' + lineCount +
                        ' lines to ' + linesSoFar + ' already processed in this transaction, ' +
                        'exceeding the synchronous ceiling of ' + MAX_LINES_PER_INVOCATION +
                        '. Move to an asynchronous path for volumes this size.');
                }

                res.quoteId = createInternal((Id) req.opportunityId, input);
                res.lineCount = lineCount;
                res.success = true;
                linesSoFar += lineCount;

            } catch (Exception e) {
                Database.rollback(sp);
                res.quoteId = null;
                res.lineCount = 0;
                res.errorMessage = e.getTypeName() + ': ' + e.getMessage();
            }
            results.add(res);
        }
        return results;
    }

    // ---------- Apex entry point ----------

    public static Id create(Id opportunityId, String payloadJson) {
        return createInternal(opportunityId, parse(payloadJson));
    }

    // ---------- core ----------

    private static Id createInternal(Id opportunityId, QuoteInput input) {
        Opportunity opp = getOpportunity(opportunityId);

        Set<String> codes = new Set<String>();
        for (LineInput li : input.lines) {
            codes.add(li.productCode);
            if (li.options != null) {
                for (LineInput o : li.options) codes.add(o.productCode);
            }
        }
        codes.remove(null);
        if (codes.isEmpty()) {
            throw new QuoteCreationException('Payload contains no product codes.');
        }

        Map<String, Product2> productsByCode = new Map<String, Product2>();
        for (Product2 p : [SELECT Id, ProductCode FROM Product2 WHERE ProductCode IN :codes]) {
            productsByCode.put(p.ProductCode, p);
        }

        List<String> missing = new List<String>();
        for (String c : codes) {
            if (!productsByCode.containsKey(c)) missing.add(c);
        }
        if (!missing.isEmpty()) {
            throw new QuoteCreationException('Unresolvable product codes: ' + String.join(missing, ', '));
        }

        Map<Id, Id> pbeByProduct = new Map<Id, Id>();
        if (opp.Pricebook2Id != null) {
            for (PricebookEntry pbe : [
                SELECT Id, Product2Id FROM PricebookEntry
                WHERE Product2Id IN :productsByCode.values()
                  AND Pricebook2Id = :opp.Pricebook2Id
                  AND IsActive = true
            ]) {
                pbeByProduct.put(pbe.Product2Id, pbe.Id);
            }
        }

        Map<String, Id> optionByKey = new Map<String, Id>();
        for (SBQQ__ProductOption__c po : [
            SELECT Id, SBQQ__ConfiguredSKU__r.ProductCode, SBQQ__OptionalSKU__r.ProductCode
            FROM SBQQ__ProductOption__c
            WHERE SBQQ__ConfiguredSKU__r.ProductCode IN :codes
              AND SBQQ__OptionalSKU__r.ProductCode IN :codes
        ]) {
            optionByKey.put(
                po.SBQQ__ConfiguredSKU__r.ProductCode + '|' + po.SBQQ__OptionalSKU__r.ProductCode,
                po.Id);
        }

        SBQQ__Quote__c quote = (SBQQ__Quote__c) toSObject(
            'SBQQ__Quote__c', sanitize('SBQQ__Quote__c', input.quoteFields));
        quote.SBQQ__Opportunity2__c = opportunityId;
        quote.SBQQ__Account__c = opp.AccountId;
        quote.SBQQ__Primary__c = false;
        insert quote;

        List<SBQQ__QuoteLine__c> parents = new List<SBQQ__QuoteLine__c>();
        for (LineInput li : input.lines) {
            parents.add(buildLine(li, quote.Id, productsByCode, pbeByProduct, null, null));
        }
        insert parents;

        List<SBQQ__QuoteLine__c> optionLines = new List<SBQQ__QuoteLine__c>();
        for (Integer i = 0; i < input.lines.size(); i++) {
            LineInput parent = input.lines[i];
            if (parent.options == null || parent.options.isEmpty()) continue;

            for (LineInput o : parent.options) {
                String key = parent.productCode + '|' + o.productCode;
                Id optionId = optionByKey.get(key);
                if (optionId == null) {
                    throw new QuoteCreationException(
                        o.productCode + ' is not a configured option of ' + parent.productCode + '.');
                }
                optionLines.add(buildLine(
                    o, quote.Id, productsByCode, pbeByProduct, parents[i].Id, optionId));
            }
        }
        if (!optionLines.isEmpty()) insert optionLines;

        return quote.Id;
    }

    private static SBQQ__QuoteLine__c buildLine(
        LineInput li, Id quoteId, Map<String, Product2> products,
        Map<Id, Id> pbes, Id requiredById, Id productOptionId
    ) {
        Product2 p = products.get(li.productCode);

        SBQQ__QuoteLine__c line = (SBQQ__QuoteLine__c) toSObject(
            'SBQQ__QuoteLine__c', sanitize('SBQQ__QuoteLine__c', li.fields));

        line.SBQQ__Quote__c = quoteId;
        line.SBQQ__Product__c = p.Id;
        line.SBQQ__Quantity__c = (li.quantity == null) ? 1 : li.quantity;
        line.SBQQ__PricebookEntryId__c = pbes.get(p.Id);

        if (requiredById != null) line.SBQQ__RequiredBy__c = requiredById;
        if (productOptionId != null) line.SBQQ__ProductOption__c = productOptionId;
        if (li.options != null && !li.options.isEmpty()) line.SBQQ__Bundle__c = true;

        return line;
    }

    // ---------- helpers ----------

    private static QuoteInput parse(String payloadJson) {
        QuoteInput input;
        try {
            input = (QuoteInput) JSON.deserialize(payloadJson, QuoteInput.class);
        } catch (Exception e) {
            throw new QuoteCreationException('Payload is not valid JSON: ' + e.getMessage());
        }
        if (input == null || input.lines == null || input.lines.isEmpty()) {
            throw new QuoteCreationException('Payload contains no lines.');
        }
        return input;
    }

    private static Integer countLines(QuoteInput input) {
        Integer n = 0;
        for (LineInput li : input.lines) {
            n++;
            if (li.options != null) n += li.options.size();
        }
        return n;
    }

    private static Opportunity getOpportunity(Id opportunityId) {
        List<Opportunity> opps = [
            SELECT Id, AccountId, Pricebook2Id FROM Opportunity WHERE Id = :opportunityId
        ];
        if (opps.isEmpty()) {
            throw new QuoteCreationException(
                'Opportunity not found or not visible to the current user: ' + opportunityId);
        }
        return opps[0];
    }

    private static Map<String, Object> sanitize(String objectApiName, Map<String, Object> fields) {
        Map<String, Object> clean = new Map<String, Object>();
        if (fields == null || fields.isEmpty()) return clean;

        Map<String, Schema.SObjectField> fieldMap = describeFields(objectApiName);

        for (String key : fields.keySet()) {
            String lower = key.toLowerCase();

            Schema.SObjectField f = fieldMap.get(lower);
            if (f == null) {
                throw new QuoteCreationException(
                    'Unknown field on ' + objectApiName + ': ' + key);
            }
            if (BLOCKED_FIELDS.contains(lower)) {
                throw new QuoteCreationException(
                    'Field is set by this service and cannot come from the payload: ' + key);
            }
            Schema.DescribeFieldResult d = f.getDescribe();
            if (!d.isUpdateable()) {
                throw new QuoteCreationException(
                    'Field is not writable for the running user: ' + key);
            }
            clean.put(d.getName(), fields.get(key));
        }
        return clean;
    }

    private static Map<String, Schema.SObjectField> describeFields(String objectApiName) {
        if (!describeCache.containsKey(objectApiName)) {
            describeCache.put(objectApiName,
                Schema.getGlobalDescribe().get(objectApiName).getDescribe().fields.getMap());
        }
        return describeCache.get(objectApiName);
    }

    private static SObject toSObject(String objectType, Map<String, Object> fields) {
        Map<String, Object> m = new Map<String, Object>(fields);
        m.put('attributes', new Map<String, String>{ 'type' => objectType });
        return (SObject) JSON.deserialize(JSON.serialize(m), SObject.class);
    }
}
```

What changed beyond the rename:

**Payload fields are now validated** against describe — the field must exist, be updateable for the running user, and not be one the service owns. `isUpdateable()` respects FLS, so this closes the gap the review flagged. Note it does not cover object-level CRUD or sharing on read; `with sharing` handles record visibility, and the Opportunity query throws a clear error if the user can't see it rather than a bare list-index exception.

**Unresolvable option codes now throw** instead of silently producing a flat line with a null `SBQQ__ProductOption__c`. That was the failure mode that inserts cleanly and breaks months later in amendments. The option query is also constrained on both sides, so an option code belonging to a *different* bundle won't match.

**Per-request savepoint** in the invocable. Each quote is independently atomic — one bad request doesn't take down quotes already built in the same transaction. Two things to know: each `setSavepoint()` counts against the DML statement limit, and rolling back does not restore consumed governor limits.

**Failures return as `Result` records** rather than throwing, so Flow can branch on `success` and read `errorMessage` instead of the whole interview faulting.

Still not addressed, deliberately: no calculation, one level of options, and the CPU ceiling is a guess. The harness rewrite covering the review's points 5 and 6 — comparing created lines against requested lines, and validating that each option resolved to the correct `ProductOption` — is a separate piece of work.
